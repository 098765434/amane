# Fork notes — amane

A fork of [amane](https://github.com/MystiaFin/amane), a declarative Rust Wayland-shell library,
maintained for the [amane-shell](https://github.com/098765434/amane-shell) desktop. It adds
xdg-popups, niri compositor services, app windows, blur shapes and vibrancy, parley text, spring
animation and more system services, as a rebasable series of commits on branch `ocbk` over
upstream's `fork-base`.

**Docs:** [docs/fork/README.md](docs/fork/README.md).
